常用公式速查

经典 12T 80C51

机器周期

Tcy = 12 / fosc

fosc 用 Hz；12MHz 时 Tcy=1μs，6MHz 时 Tcy=2μs。

定时器计数次数

N = 2ⁿ − x

n 为计数器位数，x 为初值；定时时间 T=N×Tcy。

方式 0 初值

x = 8192 − T/Tcy

13 位；TH0 与 TL0 低 5 位共同组成计数初值。

方式 1 初值

x = 65536 − T/Tcy

16 位；TH0 为高 8 位，TL0 为低 8 位。

方式 2 初值

x = 256 − T/Tcy

8 位自动重装；TH0 保存重装值，TL0 计数。

串口方式 1 波特率

Baud = 2^SMOD × fosc / [12×32×(256−TH1)]

T1 通常工作在方式 2；SMOD=0 时不倍增。

帧速率与波特率

波特率 = 每帧位数 × 帧/秒

1 起始 + 8 数据 + 1 停止 = 10 bit/帧。

ADC 分辨率

Δ = VFS / 2ⁿ

n 为 ADC 位数；量化绝对误差通常按 ±½LSB 计算。

线性标度变换

Y = D × (Ymax−Ymin)/255 + Ymin

8 位 ADC；D 为转换结果。本题 0–800℃ 对应 0–5V。

定时范围与工作方式

方式计数位数计数范围最大定时时间（Tcy）特点
方式 013 位1～81928192×TcyTLx 低 5 位 + THx 8 位
方式 116 位1～6553665536×TcyTHx、TLx 组成 16 位计数器
方式 28 位1～256256×TcyTLx 溢出后自动从 THx 重装
方式 3T0 拆为两个 8 位——仅适用于 T0；T1 停止计数
6MHz 晶振（Tcy=2μs）：方式0/1/2 最大定时范围分别为 16384μs、131072μs、512μs。12MHz 晶振（Tcy=1μs）：分别为 8192μs、65536μs、256μs。

第1章

单片机定义

在一块半导体芯片上集成微处理器、存储器、I/O接口、定时器/计数器和中断系统等功能部件，构成完整的微型计算机。

单片机与微型计算机

单片机是微型计算机发展的重要分支，面向稳定可靠、小而廉、适应控制领域的应用。

常见系列

MCS-51/8051、AVR、PIC、Motorola、MSP430、基于ARM核的32位单片机。

MCS-51 / 80C51

Intel于1980年推出MCS-51；8051是典型型号。后续厂商推出与其指令系统兼容的产品，常称80C51系列。

数制标识和基本规则

数制数码进位规则标识符位权
二进制0、1逢二进一B2的整数次幂
十进制0～9逢十进一D（可省略）10的整数次幂
十六进制0～9、A～F逢十六进一H16的整数次幂
数制的基：计数制中所具有的数码个数。数制的权：每一位所具有的值，即该位对应基数的幂。

第一章数制转换方法

二进制 / 十六进制 → 十进制

按权展开，再将各项相加

例如：0F3DH = 15×16² + 3×16 + 13 = 3901。

十进制 → 二进制

整数：除2取余、倒序；小数：乘2取整、正序

例如：19.625D = 10011.101B。

二进制 → 十六进制

以小数点为界，每4位分组，不足补0

课件示例：1111000111.100101B = 3C7.94H。

十六进制 → 二进制

每一位十六进制数替换为4位二进制

例如：2FB5H = 0010 1111 1011 0101B。

模板1：LED 流水灯（左移 / 右移）

左移初值 0x01；右移初值 0x80。LED 亮灭取决于电路有效电平。

左移：P1.0 → P1.7
led = 0x01;
for(i=0; i<8; i++)
{
    P1 = led;
    delay_ms(100);
    led <<= 1;
}
右移：P1.7 → P1.0
led = 0x80;
for(i=0; i<8; i++)
{
    P1 = led;
    delay_ms(100);
    led >>= 1;
}

模板3：外部中断 INT1 计数

INT1 下降沿触发；C51 中断号为 2。EA 与 EX1 均需开放。

volatile unsigned int X=0;

void init(void)
{
    IT1=1;       /* INT1下降沿触发 */
    IE=0x84;     /* EA=1，EX1=1 */
}

void exter1_isr(void) interrupt 2
{
    X++;
}

void main(void)
{
    init();
    while(1)

    }

模板5：PWM 输出（周期10ms、占空比55%、每10μs中断）

总次数 N=10ms/10μs=1000；高电平次数 NH=1000×55%=550；低电平次数450。

unsigned int COUNTER=0;
unsigned int PWMH=550;

void init(void)
{
    TMOD=0x02;
    TH0=0xF6;
    TL0=0xF6;
    ET0=1;
    EA=1;
    TR0=1;
}

void timer0_isr(void) interrupt 1
{
    COUNTER++;
    COUNTER%=1000;

    if(COUNTER<PWMH)
        P1_0=1;
    else
        P1_0=0;
}
模板6：四相八拍步进电机（每100ms换一拍）

每200μs中断一次，100ms/200μs=500次中断后更新一次相序；若每10ms换相，计数条件改为50。

unsigned char ndata[8]=
{
    0x08,0x0C,0x04,0x06,
    0x02,0x03,0x01,0x09
};
unsigned int timer=0;
unsigned char timer1=0;

void init(void)
{
    TMOD=0x02;
    TH0=0x38;
    TL0=0x38;
    P1=0x00;
    ET0=1;
    EA=1;
    TR0=1;
}

void timer0_isr(void) interrupt 1
{
    timer++;
    if(timer==500)
    {
        timer=0;
        timer1++;
    }
    timer1%=8;
    P1=ndata[timer1];
}
模板7：串口查询方式发送（11.0592MHz、9600bps）

SCON=40H；T1方式2；TH1=TL1=FDH；写SBUF发送，查询TI，发送完成后软件清TI。

uchar code DATA[10]=
{
    0x31,0x32,0x33,0x34,0x35,
    0x36,0x37,0x38,0x39,0x30
};

void main(void)
{
    uchar i;
    SCON=0x40;
    TMOD=0x20;
    TH1=0xFD;
    TL1=0xFD;
    TI=0;
    TR1=1;

    for(i=0;i<10;i++)
    {
        SBUF=DATA[i];
        while(TI==0);
        TI=0;
    }
    while(1);
}
模板8：ADC0809 温度采集（XBYTE + INT0）

地址、启动转换方式必须按题目接口电路确定；换算式按0～255对应0～800℃。

#include <reg51.h>
#include <absacc.h>

#define address 0x7FF8
float temp;

void Initial(void)
{
    IT0=1;
    EA=1;
    EX0=1;
    XBYTE[address]=0;   /* 按题目电路启动转换 */
}

void ad_isr(void) interrupt 0
{
    temp=XBYTE[address];
    temp=temp*1.0/255*800;
    XBYTE[address]=0;   /* 启动下一次转换 */
}

最后检查：编程题最容易丢分的地方

  • INT0 = interrupt 0；T0 = interrupt 1；INT1 = interrupt 2。
  • 使用中断时，EA 和对应中断允许位都要开启。
  • 启动定时器要写 TR0=1 或 TR1=1。
  • 定时初值必须根据题目晶振频率重新计算。
  • 方式2为8位自动重装：TH保存重装值，TL为当前计数值。
  • PWM先算总次数，再算高电平次数；周期变化时总次数也变化。
  • 共阳极与共阴极数码管段码不能混用。
  • 步进电机相序数组要与接线和转向要求相符。
  • 0xFD只适用于特定晶振、波特率和SMOD设置。
  • C语言区分大小写，语句末尾要有分号。
  • 中断服务程序访问的变量应定义在函数外部。
  • 数组下标不能越界：八拍为0～7，段码为0～9。
