# 51单片机自主复习｜交互式学习站公开演示版

单文件静态网页：题目筛选、分层答案、分步提示、随机练习、错题本、掌握标记和进度反馈。**公开版只含 6 道重新编写的通用演示题及交互架构；原课程作业、教师资料和个人学习记录均未收录。**

## 快速运行

双击 `index.html`，或用浏览器打开本地文件即可使用。无需服务器与账号。

```powershell
python -B -m unittest discover -p "test_*.py" -v
```

页面提供添加科目、录入自定义题目的入口。自定义题目和练习记录存于当前浏览器的 `localStorage`，本项目没有远程同步；清理浏览器站点数据会失去本机记录。公开演示版使用独立的存储键，不读取原学习站的历史记录。

## 技术结构

- `index.html`：HTML/CSS/原生 JavaScript 单文件，包含响应式布局与题目渲染。
- `QUESTIONS`：只含通用原创演示题；可以替换为自行编写和已授权发布的内容。
- `localStorage`：在浏览器本机保存错题、掌握标记、练习次数与用户自定义题目。
- `renderProgress()`：按操作记录计算覆盖率和**人工掌握标记率**，不是自动阅卷，也没有内置大模型/Agent。

项目的 Agent 能力应表述为**使用 AI Agent 辅助需求拆解、交互开发与测试验证**，而不是将网页说成具有智能评分或自动生成课程内容的产品。

## 发布边界

不复制原题库、教师答案、课件、浏览器数据或个人路径；不导入原项目 Git 历史。提交前逐项核对 `git diff --cached --name-only`。
