# 51 单片机考试复习站

单文件静态网页，公开展示 **44 道内置复习题**，覆盖第一章基础知识、作业 1–5 及相关章节知识点，并包含答题模板、分步提示、速查手册、错题本、进度统计和独立的**往年试卷文字模块**。老师题目按原卷大题、小题顺序展示，可展开参考答案；不嵌入或上传拍屏照片。

## 使用方法

双击 `index.html` 即可在浏览器中打开。部署到 Netlify 后，通过网站地址直接访问；与仓库连接的站点在 `main` 分支更新后自动部署。

```powershell
python -B -m unittest discover -p "test_*.py" -v
```

## 数据与隐私

- 44 道题及其网页中显示的题干、答案、来源说明都是**公开内容**；不要向公开仓库提交不准备公开的其他课件、附件或个人数据。
- “往年试卷”属于独立文字模块，不加入 44 题的计数，也不参与练习进度。来源是用户提供的“试卷A答案及评分标准”第 1—7/8 页拍屏，采用 Windows 中文 OCR 后逐题人工校对；**原 PDF 第 8 页未收到**，第一大题未拍到老师评分答案，网站把这部分独立标成“计算参考”而不是老师原话。电路图未在文字中完整复原，涉及接线需回看原件。
- 自定义科目、自定义题目、错题标记及练习记录只存在访问者当前浏览器的 `localStorage`，不会提交到 GitHub，也不会在不同设备间自动同步。清理浏览器站点数据会删除该浏览器里的记录。
- 浏览器存储键沿用旧公开演示版，避免已有访问者的自定义题目和练习记录在升级后消失。原本地复习站和公开网站各自使用独立的浏览器存储环境。
- `renderProgress()` 统计练习记录及人工标记，不代表自动阅卷或 AI 智能评分。

## 文件

- `index.html`：页面、样式、交互、44 道内置题和答题模板。
- `test_public.py`：题库数量、关键结构、试卷文字顺序、浏览器存储与敏感路径的轻量检查。

项目中的 AI Agent 用于协助需求拆解、页面开发和测试验证；网页本身没有自动生成题目或智能阅卷功能。
